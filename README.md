# Python Calculator 🧮

A simple and user-friendly GUI Calculator built using Python and Tkinter. This project performs basic arithmetic operations through an interactive graphical interface.

## ✨ Features

- Addition
- Subtraction
- Multiplication
- Division
- Clear button to reset the calculation
- Interactive graphical user interface
- Simple and easy-to-use design

## 🛠️ Technologies Used

- Python
- Tkinter

## 🚀 How to Run

1. Make sure Python is installed on your computer.
2. Clone this repository:

   git clone https://github.com/ishaxplore/python-calculator.git

3. Open the project in PyCharm or any Python IDE.
4. Run:

   python calculator.py

5. The calculator window will open and you can start performing calculations.

## 📌 Project Overview

This project was created to practice Python programming and GUI development using Tkinter. It helped me understand concepts such as functions, event handling, user input handling, and creating interactive graphical interfaces.
